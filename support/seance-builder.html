🐼 Générateur de séances Renforcement

Construis une ou plusieurs séances (blocs, échauffement/montée en charge, surcharge progressive, planning multi-semaines) puis exporte un fichier JSON importable directement dans PandaFit via Profil → Import. Les charges proposées respectent ton matériel réel si tu le charges (panneau 2) ; les dates plantées restent modifiables ensuite dans l'app (icône 📅). Utilisable à la main ou en collant un JSON généré par une IA (voir panneau 4).

1. Charger le catalogue (optionnel) 2. Charger mon matériel (optionnel) 3. Construire les séances 4. Vérifier / coller du JSON 5. Télécharger l'export

1. Catalogue d'exercices

Pour que les exercices se relient correctement au catalogue de l'app, exporte-le d'abord depuis Profil → Exercices → Export JSON, puis colle le contenu ci-dessous (ou charge le fichier). Sans catalogue chargé, tu peux quand même taper des noms d'exercice en texte libre — s'ils n'existent pas déjà dans ton catalogue app, l'import les ignorera (utilise plutôt "+ nouvel exercice custom" dans ce cas).
Aucun catalogue chargé — 0 exercice disponible en autocomplete (hors exercices custom créés ici).

2. Mon matériel

Pour que les charges cibles respectent exclusivement ton matériel réel (comme le fait la surcharge progressive dans l'app — snapping sur les charges réellement composables, bible §4.3), exporte-le depuis Profil → Mon matériel → icône de partage, puis colle le contenu ci-dessous. Sans matériel chargé, la charge cible reste un champ libre non vérifié.
Aucun matériel chargé — les charges cibles resteront en texte libre, sans vérification de faisabilité.

3. Séances

Chaque séance produit un template STRENGTH (isolation template/instance gérée automatiquement à l'import). Les dates ci-dessous sont optionnelles et restent modifiables ensuite dans l'app via l'icône 📅.

4. Mode JSON brut (pour une IA, ou sauvegarde/relecture)

Une IA (ou toi) peut coller directement un document JSON au format simplifié ci-dessous, plutôt que de remplir les champs un par un. Le bouton "Copier l'état actuel" permet aussi d'extraire ce que tu as déjà construit dans le panneau 2 (utile pour relecture ou sauvegarde externe).

5. Export vers PandaFit

Génère le fichier JSON (format PandaMoveExport) à importer depuis Profil → Import dans l'app. Le brouillon est sauvegardé automatiquement dans ce navigateur (localStorage) — tu peux fermer l'onglet et reprendre plus tard.
